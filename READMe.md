# Регуляризованное уравнивание геодезических наблюдений

## Постановка задачи

Дана геодезическая сеть из $n$ пунктов с неизвестными высотами $x_1, \dots, x_n$. Выполнено $m$ измерений $\ell_1, \dots, \ell_m$ с весами $p_i > 0$. Требуется найти вектор поправок $\hat{x} \in \mathbb{R}^n$ к начальному приближению $x_0$.

Математически задача сводится к решению системы линейных уравнений
$$A x \approx y,$$
где $A \in \mathbb{R}^{m \times n}$ — матрица коэффициентов, $y \in \mathbb{R}^m$ — вектор свободных членов, $x \in \mathbb{R}^n$ — искомый вектор поправок.

При $m > n$ system переопределена, и точного решения не существует. Задача ищется в смысле наименьших квадратов с регуляризацией.

---

## Шаг 1. Формирование уравнений поправок

Для каждого измерения $i = 1, \dots, m$:

1. Вычислить частные производные функции $f_i$ по всем неизвестным $x_j$ в точке $x_0$:
   $$A_{i,j} = \frac{\partial f_i}{\partial x_j}\bigg|_{x = x_0}, \quad j = 1, \dots, n.$$

2. Задать свободный член:
   $$y_i = \ell_i - f_i(x_0).$$

3. Задать вес $p_i > 0$, характеризующий точность измерения.

Для нивелирной сети коэффициенты принимают простой вид:
$$A_{i,\text{from}} = -1, \quad A_{i,\text{to}} = +1, \quad A_{i,j} = 0 \text{ иначе}.$$

---

## Шаг 2. Взвешивание системы

Вводится весовая матрица
$$P = \mathrm{diag}(p_1, \dots, p_m) \in \mathbb{R}^{m \times m}, \quad p_i > 0.$$

Взвешенные матрица и вектор:
$$\tilde{A} = P^{1/2} A \in \mathbb{R}^{m \times n}, \qquad \tilde{y} = P^{1/2} y \in \mathbb{R}^m,$$
где $P^{1/2} = \mathrm{diag}(\sqrt{p_1}, \dots, \sqrt{p_m})$.

Дальнейшая задача формулируется в терминах $\tilde{A}$ и $\tilde{y}$.

---

## Шаг 3. Сингулярное разложение

Вычисляется сингулярное разложение матрицы $\tilde{A}$:
$$\tilde{A} = U \, \Sigma \, V^T,$$
где:

* $U \in \mathbb{R}^{m \times n}$ — матрица с ортонормированными столбцами $u_1, \dots, u_n$:
  $$u_j^T u_k = \delta_{j,k};$$
* $V \in \mathbb{R}^{n \times n}$ — ортогональная матрица со столбцами $v_1, \dots, v_n$:
  $$v_j^T v_k = \delta_{j,k}, \quad V V^T = V^T V = I_n;$$
* $\Sigma = \mathrm{diag}(\sigma_1, \dots, \sigma_n)$ — диагональная матрица сингулярных чисел, упорядоченных по убыванию:
  $$\sigma_1 \geq \sigma_2 \geq \dots \geq \sigma_n \geq 0.$$

Сингулярные числа являются квадратными корнями из собственных значений матрицы $\tilde{A}^T \tilde{A}$:
$$\sigma_j = \sqrt{\lambda_j(\tilde{A}^T \tilde{A})}.$$

**Алгоритм вычисления** — односторонний метод Якоби. На каждом шаге выбирается пара столбцов $(p, q)$ матрицы $U$ и вычисляются величины:
$$\alpha = \sum_{i=1}^m U_{i,p}^2, \quad \beta = \sum_{i=1}^m U_{i,q}^2, \quad \gamma = \sum_{i=1}^m U_{i,p} U_{i,q}.$$

Если 
$$\frac{|\gamma|}{\sqrt{\alpha \beta}} > \varepsilon_{\text{SVD}},$$
то применяется вращение Якоби. Вычисляются параметры вращения:
$$\zeta = \frac{\beta - \alpha}{2\gamma}, \quad t = \frac{\mathrm{sign}(\zeta)}{|\zeta| + \sqrt{1 + \zeta^2}}, \quad c = \frac{1}{\sqrt{1 + t^2}}, \quad s = c\,t$$
и столбцы $p, q$ матриц $U$ и $V$ обновляются по формулам:
$$U_{:,p}' = c\,U_{:,p} - s\,U_{:,q}, \qquad U_{:,q}' = s\,U_{:,p} + c\,U_{:,q},$$
$$V_{:,p}' = c\,V_{:,p} - s\,V_{:,q}, \qquad V_{:,q}' = s\,V_{:,p} + c\,V_{:,q}.$$

Процедура повторяется до сходимости, после чего сингулярные числа вычисляются как $\sigma_j = \|U_{:,j}\|_2$, а столбцы $U$ нормируются.

---

## Шаг 4. Регуляризация Тихонова

Вместо классического МНК-решения $\hat{x} = (\tilde{A}^T \tilde{A})^{-1} \tilde{A}^T \tilde{y}$ ищется регуляризованное решение:
$$x_\alpha = \arg\min_{x \in \mathbb{R}^n} \left( \|\tilde{A} x - \tilde{y}\|_2^2 + \alpha \|x\|_2^2 \right),$$
где $\alpha > 0$ — параметр регуляризации.

Необходимое условие минимума приводит к регуляризованным нормальным уравнениям:
$$(\tilde{A}^T \tilde{A} + \alpha I) x_\alpha = \tilde{A}^T \tilde{y}.$$

Через сингулярное разложение решение записывается в явном виде:
$$x_\alpha = \sum_{j=1}^n \frac{\sigma_j}{\sigma_j^2 + \alpha} \, \langle \tilde{y}, u_j \rangle \, v_j,$$
где $\langle \tilde{y}, u_j \rangle = u_j^T \tilde{y}$ — проекция данных на $j$-й левый сингулярный вектор.

**Коэффициенты фильтра** $f_j = \frac{\sigma_j}{\sigma_j^2 + \alpha}$:

* при $\alpha \to 0$: $f_j \to 1/\sigma_j$ — получается МНК-решение;
* при $\alpha \to \infty$: $f_j \to 0$ — решение стремится к нулю;
* малые сингулярные числа $\sigma_j \ll \sqrt{\alpha}$ подавляются, что обеспечивает устойчивость.

---

## Шаг 5. Оценка уровня шума

Если априорная информация о шуме отсутствует, она вычисляется по остаточной невязке МНК-решения:
$$\rho_{\text{LS}} = \|\tilde{A} x_{\text{LS}} - \tilde{y}\|_2, \qquad \sigma_0 = \frac{\rho_{\text{LS}}}{\sqrt{m - n}}, \qquad \varepsilon = \sigma_0 \sqrt{m},$$
где $m - n$ — число избыточных измерений (степеней свободы), $\sigma_0$ — средняя квадратическая ошибка единицы веса.

---

## Шаг 6. Выбор параметра регуляризации по принципу невязки

Требуется найти $\alpha^* > 0$ такое, что
$$\rho(alpha^*) = \tau \, \varepsilon,$$
где $\rho(\alpha) = \|\tilde{A} x_\alpha - \tilde{y}\|_2$, $\tau > 1$ — параметр (обычно $\tau = 1.1$).

Определяется функция
$$d(\alpha) = \rho(\alpha) - \tau \, \varepsilon.$$
Она монотонно возрастает по $\alpha$:
$$\rho(0) = \rho_{\min} \leq \tau \varepsilon, \qquad \lim_{\alpha \to \infty} \rho(\alpha) = \|\tilde{y}\|_2.$$
Корень единственный.

**Поиск корня:**

1. Задать начальный интервал $[\alpha_L, \alpha_R]$.
2. Расширить интервал, пока $d(\alpha_L)$ и $d(\alpha_R)$ не станут разных знаков:
   * если $d(\alpha_L) > 0$, уменьшать $\alpha_L$ в 10 раз;
   * если $d(\alpha_R) < 0$, увеличивать $\alpha_R$ в 10 раз.
3. Бисекция. Пока $|\alpha_R - \alpha_L| > \delta_\alpha$:
   $$\alpha_M = \frac{\alpha_L + \alpha_R}{2};$$
   * если $d(\alpha_M) > 0$, положить $\alpha_R = \alpha_M$;
   * иначе положить $\alpha_L = \alpha_M$.
4. Итоговый параметр:
   $$\alpha^* = \frac{\alpha_L + \alpha_R}{2}.$$

---

## Шаг 7. Итоговое решение

Регуляризованное решение при найденном $\alpha^*$:
$$\hat{x} = x_{\alpha^*} = \sum_{j=1}^n \frac{\sigma_j}{\sigma_j^2 + \alpha^*} \, \langle \tilde{y}, u_j \rangle \, v_j.$$

Уравненные высоты пунктов:
$$h_i = x_{0,i} + \hat{x}_i, \qquad i = 1, \dots, n.$$
